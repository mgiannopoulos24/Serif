# Icons

SVGs in this directory are from **Material Design Icons Light** by Pictogrammers,
<https://github.com/Pictogrammers/MaterialDesignLight>, used under the
Apache License 2.0 (Pictogrammers Free License). `close.svg` uses the geometry of
the regular **Material Design Icons** `close` glyph (<https://github.com/Templarian/MaterialDesign>,
same licence) since the Light set has no plain ×.

| File          | MDL name  | Used for                                   |
|---------------|-----------|--------------------------------------------|
| `menu.svg`    | `menu`    | Navigation block: open button              |
| `close.svg`   | `close` (MDI, regular set) | Navigation / search overlay close buttons — MDI geometry redrawn as a 1.2px stroke to match the Light set |
| `magnify.svg` | `magnify` | Search block: icon button                  |
| `chevron-right.svg` | `chevron-right` | Breadcrumb separator (Yoast / RankMath) |

They are inlined by `inc/block-filters.php`. See `CREDITS.md` at the theme root.
